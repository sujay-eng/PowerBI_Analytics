Sales Analytics Dashboard | Power BI
About the Project

This project is based on the Online Retail dataset. I used Microsoft Power BI to explore the sales data and understand different aspects of the business.

The main objective was to analyze sales performance, identify trends and understand customer and product purchasing patterns through interactive visualizations.

Tools & Technologies
Microsoft Power BI
Power Query
DAX
Microsoft Excel
Project Workflow
Imported the Online Retail dataset into Power BI.
Cleaned and transformed the data using Power Query.
Prepared the data for analysis.
Created calculated measures using DAX.
Developed an interactive dashboard to visualize sales performance.
Areas of Analysis
Overall sales performance
Revenue trends
Product-wise sales analysis
Customer purchasing patterns
Order and quantity analysis
Key Performance Indicators (KPIs)

The dashboard focuses on important sales metrics such as:

Total Revenue
Total Orders
Quantity Sold
Average Order Value
Product Performance
Key Learnings

While working on this project, I gained practical experience in data cleaning, data transformation, data modeling and creating DAX measures.

I also learned how to use Power BI visualizations to present sales information in a more understandable way.
